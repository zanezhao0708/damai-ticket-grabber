# damai-ticket-grabber

大麦网抢票工具（Web 版）—— 仅限个人学习研究使用，请勿用于盈利或代抢。

## ⚠️ 免责声明

- 本项目仅用于个人技术学习与研究目的，不用于任何盈利活动
- 使用自动化工具可能违反大麦网《用户服务协议》，产生的一切后果由使用者自行承担
- 请尊重公平购票秩序，理性消费

## ✨ 功能

- **网页操作界面**：浏览器打开即用，无需桌面环境
- **⚡ 极速模式**：开售前预热页面并预选场次/票档，开售瞬间 JS 注入直接点击购票按钮（比手动操作快）
- **实时日志**：网页终端实时显示运行状态，彩色分级
- **自动登录引导**：首次运行手动扫码登录，Cookie 自动保存，后续免登录
- **配置持久化**：参数自动保存在浏览器 localStorage，刷新不丢

## 🚀 快速开始（Web 版）

### 方式一：一键脚本（推荐）

- **Windows**：双击 `start.bat`（自动装依赖 → 启动 → 自动打开浏览器）
- **Mac/Linux**：终端执行 `./start.sh`

### 方式二：手动命令

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动 Web 服务
python app.py

# 3. 浏览器打开
# http://localhost:8787
```

### 使用步骤

1. 打开大麦网演出详情页，从地址栏复制演出ID（`item.htm?id=` 后面的数字）
2. 在网页中填写：
   - **演出ID**：如 `1068684284719`
   - **场次关键词**：模糊匹配，如 `13:30` 或 `周六`（可留空自动选）
   - **票档关键词**：模糊匹配，如 `88元` 或 `前区互动`
   - **数量**：购买张数（受大麦限购约束，一般最多 6 张）
   - **开售时间**（可选）：格式 `2026-08-20 12:00:00`，留空则立即开始
3. 点击 **▶ 开始抢票**
4. 弹出的浏览器窗口中手动完成登录（扫码/验证码），回到网页点 **✓ 我已登录完成**
5. 抢到后浏览器停在付款页，**请立即手动完成支付**

## 🖥️ 备选：桌面 GUI 版

```bash
python damai_gui.py
```

功能与 Web 版一致（tkinter 桌面窗口）。

## ⚙️ 极速模式原理

1. 开售前 60 秒自动打开详情页并预选好日期/场次/票档/数量（页面预热，DOM 已渲染、连接已建立）
2. 开售瞬间通过 JS 注入在页面上下文中直接查找并 `.click()` 购买按钮（跳过 Selenium 鼠标动作链与可点击性检查，毫秒级触发）
3. 50ms 级高频轮询购票按钮是否出现，出现即点
4. `eager` 页面加载策略：DOM 就绪即返回，不等图片/广告资源

## 📁 项目结构

```

├── damai_gui.py           # 桌面 GUI 入口（tkinter，备选）

```

## 🔧 已知的现实限制

- 滑块/点选验证码出现时需要人工介入
- 热门演出开售瞬间服务端可能直接排队/限流，脚本无法绕过服务端限制
- 大麦部分演出仅支持 APP 购买，网页端会提示"该渠道不支持购买"（此类演出无法用本工具）
- 实名制演出需提前在大麦账号中添加好观演人信息
- 如部署到远程服务器：登录扫码需在服务器端浏览器完成，个人使用建议本机运行
